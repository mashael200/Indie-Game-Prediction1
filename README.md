# Steam Games Data Analysis & Cleaning 🎮📊

## Overview
This project focuses on loading, inspecting, cleaning, and preprocessing a dataset containing information on over 27,000 Steam games (`SteamGames.csv`). The data was processed using Python and Pandas to prepare it for exploratory data analysis (EDA) and machine learning modeling.

## Key Features & Data Processing Steps
* **Data Cleaning:** Removed full duplicates and filtered missing records.
* **Feature Engineering:** Calculated the average estimated owners (`owners_clean`) from numerical range strings.
* **Datetime Parsing:** Standardized `release_date` into proper datetime objects.
* **Feature Selection:** Filtered 12 essential attributes including ratings, prices, and playtimes.

## Technologies Used
* **Language:** Python
* **Libraries:** Pandas, NumPy
